# Mode pair

Le mode pair permet de travailler une étape avec l’agent, avec une organisation validée explicitement, des blocs, des points de contrôle et une reprise durable.

Consulte le [guide complet du travail en pair](MODE-PAIR.md) pour les commandes, les garanties de conservation et les vérifications.

Les conversations créées avec les versions 1.19 et 1.20 sont conservées lors de la mise à jour. Les travaux en cours demandent une reprise explicite du cadrage afin de convenir des blocs restants. Un livrable déjà prêt à relire reste disponible pour validation.
