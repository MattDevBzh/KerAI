# Feature Studio 1.20.0 — Le contexte prend son envol

Dans le **QG vivant**, le passage de relais entre deux étapes se voit désormais : **quatre avions en papier** quittent le personnage de l’étape précédente et rejoignent celui qui démarre, avec des départs décalés pendant **cinq secondes**.

- L’animation accompagne le démarrage réel d’une nouvelle tentative à partir de la deuxième étape, aussi bien en lancement classique qu’en mode pair. L’agent commence immédiatement et les postes restent cliquables.
- Les trajectoires suivent les personnages lorsque les postes changent de ligne ou que le zoom évolue.
- Les messages de l’agent, les reprises de lots en pair, la première étape et la réouverture d’une session ne déclenchent pas de nouveau vol.
- Avec la réduction des animations, le passage est simplement indiqué par un texte. Les couleurs forcées restent prises en charge.

Cette version conserve le mode pair, les statistiques, les actions groupées sur les sessions, l’héritage des profils d’agents et les relectures distantes déjà publiés.

Recette locale : format, typage, compilation, **689 tests métier réussis** (4 tests conditionnels ignorés) et **231 scénarios Chromium réussis**, dont 17 consacrés au QG. Les tests automatiques n’envoient aucun prompt Copilot payant.
