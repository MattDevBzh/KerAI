# Feature Studio v1.4.0 — Avatars, fenêtre dédiée et sessions multi-projets

Cette release réunit les changements intégrés dans `main` depuis la dernière version publiée, v1.1.1.

## Nouveautés

- **20 avatars pixel art** de métiers différents, vus de face et sur fond transparent. Chacun dispose d’une pose de repos, d’un GIF de travail à quatre images et d’une pose de réussite. Les anciens profils et kits conservent leurs identifiants.
- **Fenêtre Feature Studio dédiée**, réutilisable, avec création d’un raccourci Windows sur le Bureau pour VS Code ou VS Code Insiders.
- **Catalogue personnel de projets** : ajout de dossiers, noms personnalisés, choix du projet actif et sélection mémorisée. Une session peut réunir plusieurs projets ; chaque action et chaque restauration ciblent le dépôt concerné.
- **Équipes composables par glisser-déposer** : nouvelles features en brouillon, ajout d’avatars ou d’équipes, ordre et configuration des interventions jusqu’à la première tentative. Les agents favoris sont partagés entre les projets.
- **Contexte plus souple** : les skills absentes sont signalées dans l’aperçu et peuvent être explicitement exclues ; le lancement reste bloqué si une skill manquante est conservée.
- **Correctifs d’interface** : panneau de composition plus large, projet actif synchronisé avec la sélection mémorisée, nom personnalisé du projet dans la barre latérale et sélecteurs d’avatars adaptés aux petits écrans.

## Installation et mise à jour

1. Télécharger [feature-studio-1.4.0.vsix](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.0/feature-studio-1.4.0.vsix).
2. Dans VS Code : **Extensions → … → Installer à partir du VSIX…**, puis sélectionner ce fichier.
3. Recharger la fenêtre et vérifier que la fiche de l’extension affiche **1.4.0**.
4. Ouvrir **Feature Studio : ouvrir le cockpit**. Le raccourci Windows peut être créé depuis **Réglages → Espaces de travail** ou la palette de commandes.

Prérequis : VS Code **1.110+**, Git et GitHub Copilot CLI installé et authentifié. Les sessions multi-projets utilisent les dossiers sélectionnés ; l’isolation en worktree reste disponible pour les sessions à un seul projet.

## Vérification du paquet

La publication attend les validations Linux et Windows. Le VSIX est construit depuis le commit de la release, son archive ZIP et ses versions internes sont vérifiées, puis son contenu extrait est chargé dans un vrai hôte VS Code. Le paquet téléversé est téléchargé à nouveau et comparé à son empreinte avant publication.

Le fichier [SHA256SUMS](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.0/SHA256SUMS) permet de vérifier le téléchargement avec `Get-FileHash .\feature-studio-1.4.0.vsix -Algorithm SHA256` sous PowerShell.

Les tests automatisés utilisent des fixtures pour Copilot et Azure DevOps : aucun prompt Copilot payant n’est envoyé. Le lancement natif du raccourci Windows et une session avec ton compte Copilot restent à vérifier sur ton poste.
