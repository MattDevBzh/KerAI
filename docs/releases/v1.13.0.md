# Feature Studio 1.13.0 — Des équipes adaptées à chaque feature

Choisis les interventions utiles à ton travail avant de commencer, puis garde la main sur les étapes facultatives pendant le parcours.

- **Obligatoire ou facultative, par intervention.** Le choix apparaît dans les modèles de parcours, les équipes issues d’une discussion et la composition de chaque feature. Adapter une feature ne modifie pas l’équipe source.
- **Le pilote attend ton choix.** Une notification VS Code et un bandeau proposent **Exécuter et continuer**, **Passer et continuer** ou **Décider plus tard**. Fermer la notification ou rouvrir le cockpit conserve la pause.
- **Un passage reste visible.** Les étapes passées sont distinctes des validations dans le parcours, les cartes, le Métro, le bilan et les exports. Aucun livrable ni test réussi n’est attribué à une intervention non exécutée.
- **Des reprises cohérentes.** Une correction en amont ou une restauration remet les choix concernés en attente tout en conservant les décisions historiques. Les doubles clics et anciennes notifications sont refusés. Une étape déjà tentée ne peut pas être passée pour masquer un échec.
- **Les contrôles restent en place.** Checkpoints, confirmations, budgets, critères, remarques bloquantes et validation finale humaine restent applicables. Les anciennes équipes restent obligatoires par défaut.

La passe de corrections couvre notamment la validation finale avec interventions passées, les refus de décision affichés dans le bandeau et les routes de correction visant une intervention auparavant passée.
