# Feature Studio 1.15.0 — Relecture distante Git

Les agents de relecture peuvent maintenant consulter des branches poussées sans checkout et sans toucher aux modifications locales du projet.

- Lecture des skills et templates personnels depuis les outils de Feature Studio.
- Récupération des branches et commits dans un cache utilisateur, diffs et fichiers paginés, vérification des nouvelles publications sur les branches.
- Rapports personnels enregistrables en mode lecture seule et ouvrables depuis leur lien dans le compte rendu.
- Les droits du profil restent explicites : ajouter `studio_remote_review` et `studio_write_review_report`, ou réinstaller le kit personnel mis à jour. La skill `code-review-mattpocock` et le template existants sont réutilisés.

Télécharger le VSIX ci-dessous, utiliser **Extensions : Installer à partir du VSIX**, puis recharger la fenêtre. [Configuration et limites](../REMOTE_REVIEW.md).

Les tests automatisés couvrent l'isolation du projet, les lectures paginées, les ressources personnelles, les chemins refusés et la protection des rapports modifiés. L'authentification au dépôt Azure DevOps de chaque utilisateur reste à vérifier avec sa connexion Git habituelle.
