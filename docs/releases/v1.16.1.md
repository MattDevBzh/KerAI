# Feature Studio 1.16.1 — Télécharger les comptes rendus en Markdown

Dans une feature, ouvre l’étape puis **Livrable → Télécharger .md**. Choisis le nom et l’emplacement dans la fenêtre d’enregistrement de VS Code.

- Le fichier contient le Markdown intégral du compte rendu affiché, sans ajout ni transformation.
- Une ancienne tentative peut être sélectionnée puis téléchargée. Le nom proposé indique la feature, l’étape, le numéro de tentative et la version du rapport.
- Une tentative doit être terminée avant l’export. Enregistre ou abandonne un éventuel brouillon avant de télécharger le rapport.
- L’export ne lance aucun agent et ne consomme pas de crédits.

Télécharge le VSIX joint, utilise **Extensions : Installer à partir du VSIX**, puis recharge la fenêtre.

Publication sans exécution des suites de tests, à la demande de l’utilisateur. La compilation, le typage et l’intégrité du VSIX sont contrôlés ; le paquet téléchargé depuis la release est vérifié avec son SHA-256.
