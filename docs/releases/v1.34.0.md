# Feature Studio 1.34.0 — Des sessions à ta main

Cette version rassemble quatre améliorations du travail quotidien :

- **Modules personnalisables** : depuis « Personnaliser l’affichage », masque les cadres inutiles et déplace les autres par glisser-déposer ou avec les flèches. Le choix est mémorisé pour toutes tes sessions et tes projets. Les brouillons sont conservés ; une décision en attente reste accessible par un raccourci, même si son module est masqué.
- **Réponses automatiques au choix** : décoche « Répondre automatiquement aux choix recommandés » dans les réglages du pilote ou directement pendant l’exécution. Tu réponds alors toi-même et l’autopilote reprend ensuite. Les réponses déjà fournies restent dans son historique.
- **Conversation ouverte avant validation** : après une tâche solo terminée, écris directement à l’agent sans devoir changer de mode au préalable. L’échange reprend dans la même conversation ; une explication conserve le livrable et les permissions, et l’étape attend toujours ta validation.
- **Grands worktrees** : les points de restauration réutilisent les contenus déjà enregistrés dans Git et copient seulement les contenus supplémentaires. Le seuil de 10 000 fichiers et 64 Mio s’applique à ces copies. Les anciens points restent lisibles, les fins de ligne Windows sont conservées et les commits nécessaires restent disponibles pour restaurer les fichiers.

L’inventaire et la lecture des fichiers restent nécessaires pour vérifier leur contenu ; l’inventaire possède une limite distincte de 250 000 entrées. Cette optimisation réduit les copies, sans supprimer les points de restauration ni modifier les fichiers, l’index ou la branche d’origine.

Installe le VSIX puis recharge la fenêtre VS Code. Vérifie **1.34.0** dans la fiche de l’extension. L’archive et son empreinte SHA-256 sont vérifiées avant publication ; les tests automatiques n’envoient aucun prompt Copilot payant.
