# Feature Studio v1.4.1 — Le logo L’équipe

Feature Studio adopte le logo choisi : trois agents turquoise, violet et corail qui travaillent ensemble.

- Nouveau logo dans la fiche de l’extension, le volet d’accueil, l’onglet Feature Studio et le cockpit, y compris son écran de chargement.
- Déclinaison monochrome pour la barre d’activité VS Code et PNG transparent partagé par les écrans.
- **Créer le raccourci Windows** applique automatiquement la nouvelle icône. Elle est copiée dans les données du cockpit pour rester disponible après le remplacement du dossier de l’extension lors d’une mise à jour.
- Le raccourci existant peut être actualisé en relançant cette même commande. Le fichier ICO est aussi joint à cette release pour une modification manuelle.

## Installation

1. Télécharger [feature-studio-1.4.1.vsix](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.1/feature-studio-1.4.1.vsix).
2. Dans VS Code : **Extensions → … → Installer à partir du VSIX…**, puis recharger la fenêtre.
3. Dans **Réglages → Espaces de travail**, cliquer sur **Créer le raccourci Windows**, ou utiliser la commande du même nom dans la palette.

Pour changer l’icône manuellement : télécharger [feature-studio.ico](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.1/feature-studio.ico), puis ouvrir les **Propriétés → Raccourci → Changer d’icône** du raccourci. Conserver l’ICO à l’emplacement choisi.

La fenêtre reste hébergée par VS Code : son icône native dans la barre des tâches et son regroupement dépendent de VS Code et de Windows.

## Validation

La publication attend la CI Linux et Windows, le chargement du contenu du VSIX dans un vrai hôte VS Code et le contrôle des fichiers téléchargés. Le test de l’icône vérifie sa conservation après suppression du fichier source, son remplacement et la préservation de l’ancienne copie en cas d’échec. Le smoke du paquet vérifie la présence du PNG, du SVG et des sept tailles de l’ICO.

[SHA256SUMS](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.1/SHA256SUMS) couvre le VSIX et l’ICO. Le clic natif sur le raccourci Windows reste à vérifier sur le poste utilisateur.
