# Feature Studio 1.35.0 — Reprendre avec un contexte compact

## Une synthèse avant de relancer

Dans la fenêtre de lancement ou de reprise, ouvre **Compacter l’historique** puis **Générer une synthèse IA**. Le nombre maximal d’appels est affiché avant le clic : ils utilisent le modèle de l’étape et consomment des crédits. Les anciens livrables sélectionnés et les échanges pair sont traités par parties, puis réunis dans une synthèse.

Relis et ajuste le texte, puis clique **Appliquer cette synthèse**. L’aperçu recalculé montre la taille finale avant lancement. Le besoin, les critères, les instructions, les réponses humaines et les remarques actuelles restent transmis selon leur sélection ; la compaction ne les résume pas. Les rapports originaux ne sont pas modifiés. **Rétablir l’historique complet** retire la synthèse du lancement.

La reprise ouvre une nouvelle conversation Copilot pour éviter de réinjecter l’ancien historique natif. Si les sources résumées changent avant lancement, la synthèse est refusée et doit être retirée ou régénérée. La synthèse est un contexte de passation, pas une validation ni une preuve de test.

L’opération peut être arrêtée. Ses réponses et sa consommation restent dans une discussion « Compaction », séparément du budget d’exécution de la feature. Aucun accès au dépôt, outil, hook ou MCP n’est fourni à l’agent chargé de la synthèse. Les limites sont de 480 000 caractères de sources et 12 000 caractères de synthèse ; une réponse trop longue est conservée dans Discussion mais n’est pas appliquée. La limite du prompt reste réglable jusqu’à 500 000 caractères dans Budget ; une compaction ne garantit pas que tous les autres blocs tiennent dans cette limite.

## MCP par défaut dans la session

Dans les paramètres de l’agent, **Configurer → MCP par défaut de cet agent dans la session** permet de sélectionner les serveurs activés dans Réglages. L’enregistrement actualise aussi les MCP de cette étape dans l’autopilote déjà configuré. Ces choix restent propres à cette session et ne modifient pas l’agent de base. Un lancement manuel permet toujours un choix ponctuel différent.

Les serveurs sélectionnés devenus indisponibles restent affichés : réactive-les ou décoche-les avant de lancer. Les règles de permissions et les restrictions des phases de discussion ou de planification restent applicables.

## Installation

Installe le VSIX et recharge la fenêtre VS Code. Vérifie **1.35.0** dans Extensions. Le stockage passe en v14 ; les sessions existantes migrent, et les anciennes versions de l’extension refusent ce nouveau format. Les tests automatiques utilisent des réponses simulées pour la synthèse, sans prompt payant. L’archive distribuée et son empreinte SHA-256 sont vérifiées avant publication.
