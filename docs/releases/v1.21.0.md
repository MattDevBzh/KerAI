# Feature Studio 1.21.0 — Travailler en pair

Cette version complète le mode pair et conserve les évolutions publiées jusqu’à la v1.20.0.

Une étape peut désormais se faire avec l’agent dans un espace de travail commun, depuis la préparation du contexte jusqu’à la validation de son résultat.

- **Préparer le binôme.** Le bouton **Démarrer en mode pair** ouvre le contexte habituel avec le rythme souhaité, les explications et les préférences. L’agent propose ensuite une organisation dans la conversation ; le travail commence après sa validation explicite.
- **Avancer à son rythme.** Petits pas, blocs avec points de contrôle ou réalisation en une fois après le cadrage. Les messages, les décisions et les résultats restent associés à la même tentative.
- **Passer la main et revenir.** Le bouton **Continuer cette étape en solo** confie les blocs restants à l’agent. Il est possible de revenir en pair, d’envoyer un message pendant le travail ou de mettre en pause en conservant les changements réalisés.
- **Reprendre sans perdre le fil.** Les brouillons, les échanges et les organisations sont conservés. Après fermeture ou interruption, la reprise est explicite. Les anciennes tentatives restent consultables, même après une relance classique.
- **Corriger puis valider.** Les corrections passent par une nouvelle organisation convenue. Le compte rendu rassemble les travaux et les décisions ; **Valider l’étape et revenir à la session** applique les vérifications habituelles et retrouve la session d’origine.
- **Garder la maîtrise.** Le cadrage n’exécute pas d’outil du projet. Le passage en solo conserve les permissions, les questions humaines et la validation finale. Chaque appel est compté dans le budget ; le temps de réponse humain est exclu du délai d’exécution.

Le stockage passe à la version 7 pour conserver ces échanges et empêcher un ancien client de les écraser. Les sessions existantes sont migrées lors de leur ouverture, y compris les conversations pair de la v1.19 et de la v1.20. Leur historique et leur contexte sont conservés ; les travaux en cours demandent un nouveau cadrage explicite, les livrables prêts restent à relire.

## Validation

- Validation locale complète : format, TypeScript, **700 tests métier réussis** (4 ignorés) et construction de l’extension.
- **234 scénarios d’interface réussis**, dont la préparation pair, les commandes versionnées, les brouillons, les corrections, les vues compactes et le passage de contexte du QG.
- Migration des conversations v1.19/v1.20 testée dans quatre états, refus d’un contexte altéré et reprise explicite sans outil de projet. Les tests utilisent des réponses modèle simulées ; aucun prompt Copilot payant.
- Chargement réel du paquet extrait dans VS Code Insiders réussi : activation, cockpit, persistance v7 et parcours hôtes.
- La publication automatique vérifie Linux et Windows, charge le VSIX dans VS Code et contrôle les fichiers téléchargés avec leur SHA-256.
