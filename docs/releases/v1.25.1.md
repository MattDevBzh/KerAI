# Feature Studio 1.25.1 — Diagnostic natif et validation

Cette version améliore le diagnostic des outils natifs Copilot.

- Lorsqu’un diagnostic échoue, Feature Studio conserve le catalogue d’outils effectivement reçu et détaille les capacités obligatoires manquantes.
- Les tests couvrent explicitement le message de diagnostic.
- Prettier reste disponible pour le formatage manuel, mais ne bloque plus `npm run check`. Le typecheck, les tests et la compilation restent exécutés.

Installe le VSIX puis recharge la fenêtre VS Code pour utiliser cette version.
