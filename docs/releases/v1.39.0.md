# Feature Studio 1.39.0

Deux nouveaux kits transforment tes sources en documents adaptés à leurs lecteurs.

- **Présentation et préparation** : cinq agents pour cadrer ton objectif, analyser le document, préparer le support de présentation, rédiger ton guide personnel et vérifier l’ensemble. Le niveau de l’auditoire et celui du présentateur sont traités séparément.
- **Audit de code et restitution** : six agents pour affiner les directives, planifier l’audit, constituer le dossier brut, expliquer les résultats au demandeur, les adapter à l’auditoire cible et effectuer une validation globale. Les versions partagent les mêmes preuves, constats et limites de couverture.
- **Importer un document** dans la création de session ou le contexte de lancement : TXT, Markdown, PDF texte, Word DOCX et HTML. Le texte est extrait localement et affiché avant ajout ; le contexte existant est conservé. Les scans nécessitent une version OCR ; les images et graphiques ne sont pas interprétés par l’extraction.
- **Télécharger en PDF ou texte**, en complément des exports Markdown, Word, PowerPoint et HTML. Chaque livrable reste téléchargeable séparément, sans nouvel appel au modèle.
- **Nouvelle session** propose directement les deux parcours. Les kits s’installent au niveau utilisateur et préservent les personnalisations. Le travail reste en lecture seule et chaque étape demande une validation humaine.

Ouvre **Atelier → Kits** pour explorer les équipes, puis **Nouvelle session → Préparer une présentation / Auditer un projet**. Le [guide des deux kits](../PRESENTATION-AUDIT-KITS.md) détaille les étapes, les formats et les limites.

La qualité des documents et la correction du code sont évaluées séparément. Un audit incomplet, une source inaccessible ou un test non exécuté ne devient pas une validation favorable. Les rendus des fichiers exportés restent à vérifier avant diffusion.
