# Feature Studio 1.31.1

- Applications locales, intranet et distantes en HTTP/HTTPS, avec URL de démarrage complète.
- Outils de lecture du navigateur disponibles pendant les échanges, et choix de l’application vérifié avant de lancer le Navigateur.
- Skills du Navigateur consultables depuis Applications ; filtres Agents et Skills indépendants.
- Possibilité de passer une étape facultative arrêtée, après confirmation, en conservant ses tentatives et modifications.
- Validation humaine d’une relecture malgré les remarques, après avertissement, dans la session, l’éditeur et le mode pair. Les remarques restent visibles et leur acceptation est conservée pour la clôture.

Compilation TypeScript, contrôles ciblés et intégrité du VSIX vérifiés localement. Les tests navigateur ajoutés restent à exécuter avec un Chromium fonctionnel ; la recette Windows reste à effectuer.

Installation : télécharger le VSIX puis utiliser « Extensions : Installer depuis VSIX… » dans VS Code ou VS Code Insiders. Recharger la fenêtre après installation et préparer une nouvelle tentative pour recevoir le catalogue d’outils actualisé.
