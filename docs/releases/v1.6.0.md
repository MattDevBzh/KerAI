# Feature Studio 1.6.0 — L’Observateur de session

**Analyser cette session** examine une feature entière, toutes ses phases et tentatives, sur une copie figée des traces disponibles. Choisissez le modèle, le maximum d’appels et le budget avant le lancement. Le rapport présente les améliorations phase par phase, les sources, les commentaires globaux, les coûts et les modèles de la feature et de l’Observateur. Export HTML autonome ou Markdown.

Pendant le scan, un bandeau animé affiche l’avatar, la phase active, les parties examinées et la synthèse finale. Il reste visible lorsque le rapport est fermé, permet d’arrêter l’analyse et respecte la réduction des mouvements.

Les journaux durables disposent d’une limite initiale de 256 Mio par session, réglable de 1 à 4 096 Mio dans les paramètres du projet. La suppression définitive d’une session nettoie ses journaux, rapports et données associées ; elle conserve les objets partagés, fichiers du projet, branches et worktrees. Un nettoyage interrompu reprend au démarrage.

Cette version conserve les discussions, le cockpit multi-projets, les équipes et les avatars de la v1.5.0. Les sessions existantes migrent vers le stockage v5 en conservant leurs données connues ; un ancien binaire refuse ce nouveau format. Les anciennes traces manquantes ne sont pas reconstituées. Une ligne finale coupée est sauvegardée avant reprise et la couverture reste signalée comme partielle.

Les crédits sont ceux communiqués par Copilot, pas une facture en euros. Une mesure absente reste inconnue ; échecs et annulations restent comptabilisés. Aucun prompt Copilot payant n’est envoyé par les tests automatiques.

Installation : télécharger le VSIX joint, puis **Extensions → … → Installer à partir du VSIX…** et recharger la fenêtre. L’empreinte du paquet et de l’icône Windows figure dans `SHA256SUMS`.
