# Feature Studio 1.29.0 — QG grand écran et navigation documentée

## QG grand écran

- **Agrandir le QG** ouvre une scène de suivi destinée à un écran secondaire. Le cockpit peut être détaché dans une fenêtre indépendante et affiché en plein écran.
- Les messages publics de l’agent courant apparaissent dans une **bulle BD**. Les avions en papier accompagnent les transmissions réelles ; les sous-tâches ouvrent leur **atelier dédié**, avec leur numéro, le total et leur titre.
- Chaque agent peut écrire un **tableau manuscrit** : étapes du plan ou tâche courante, notes, ligne en cours et tâches barrées. Le plan initial et les mises à jour sont conservés par tentative. Les couleurs suivent tous les thèmes, y compris les variantes claires et sombres.
- Les longues listes défilent par pages. **Réduire pour intervenir** retrouve la bonne étape et ses demandes humaines ; la vue grand écran ne répond ni ne valide à ta place.

## Navigation documentée

- Nouvel espace **Applications** : profils et droits, bibliothèque de parcours versionnée, import JSON, démonstration dans un navigateur dédié, édition, variantes, historique et rejeu déterministe.
- Nouveau rôle **Navigateur** et quatre compétences fournies. Les autres agents utilisent un contexte figé par tentative, contribuent au référentiel et demandent une intervention humaine lorsque le contexte manque.
- Inspection ciblée de l’écran, pistes de code, captures masquées et comparaison, reçus de preuves et recherche bornée. Les applications cibles n’ont pas besoin d’un composant ou d’un script permanent ajouté par KerAI.
- Journal de campagne A/B pour mesurer les coûts déclarés et observés, les échecs, l’apprentissage et l’entretien. Aucun gain économique n’est présumé.
- Stockage version 11, avec conservation des historiques existants. Le runtime Playwright est livré dans le paquet ; le navigateur doit être disponible sur le poste.

## Installation

Télécharger le VSIX et le fichier SHA256SUMS de cette release, vérifier l’empreinte, puis installer le VSIX dans VS Code et recharger la fenêtre. La fiche de l’extension doit afficher **1.29.0**.
