# Feature Studio 1.29.1 — Résultat visible dans la fenêtre de création

- La création affiche son avancement dans la fenêtre elle-même et indique clairement que la demande est en cours.
- En cas d’échec, un encadré « Impossible de créer la session » reçoit le focus et devient visible, même dans une petite fenêtre. Le nom, le contexte et les choix du formulaire sont conservés.
- Les erreurs de validation du formulaire et d’initialisation du projet reviennent à la bonne demande. Le détail est aussi journalisé dans la sortie **Feature Studio**, après masquage des secrets reconnus.
- Réessayer un formulaire inchangé réutilise la même demande, afin de retrouver une session déjà préparée si son enregistrement avait échoué.

Cette version corrige le retour d’état et d’erreur. La cause précise du refus signalé sur le poste Windows concerné reste à confirmer à partir du message affiché ; sa résolution n’est pas présumée.

## Installation

Télécharger le VSIX de cette release, l’installer avec **Extensions : Installer à partir du VSIX**, puis recharger la fenêtre de VS Code. Vérifier que la fiche Feature Studio affiche **1.29.1**. Relancer la création et relever le texte de l’encadré si elle échoue encore.

Le QG grand écran, les tableaux adaptés aux thèmes et la navigation documentée de la 1.29.0 sont conservés. Créer une session ne lance aucun agent.
