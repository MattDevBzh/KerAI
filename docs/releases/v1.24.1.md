# Feature Studio 1.24.1 — Recherche native compatible avec rg

Cette version corrige le blocage **« Copilot natif indisponible avant tout prompt : Catalogue natif inattendu : rg »**.

Copilot peut présenter la recherche dans les fichiers sous le nom `grep`, `rg`, ou les deux. Feature Studio accepte maintenant ces trois catalogues, en lecture seule comme pendant le travail, sans exiger simultanément les deux noms.

Les contrôles sur les outils obligatoires, les doublons, les outils non autorisés et les permissions restent actifs. Les outils d’écriture et de terminal restent interdits aux conversations en lecture seule. Le diagnostic ne recommande plus systématiquement une mise à jour du CLI.

Le SDK reste en version 1.0.20 et le CLI de référence en version 1.0.102. Ce correctif ne nécessite pas de migration des données.

Installe le nouveau VSIX, recharge VS Code, puis lance **Réglages → Vérifier la connexion** avant de reprendre ton étape.

Validation : tests de régression des catalogues `grep`, `rg` et mixtes, des capacités manquantes et des outils interdits ; tests du démarrage de l’adaptateur avec `rg` seul. La publication est conditionnée aux contrôles Linux/Windows, au catalogue du vrai CLI 1.0.102, au chargement du VSIX dans VS Code et à la vérification des empreintes des fichiers publiés.
