# Feature Studio 1.27.0 — Les compétences réellement chargées

Les étapes Copilot natives utilisent désormais les skills du catalogue KerAI à travers le runtime. Les compétences ordinaires sont chargées à la demande ; les compétences à invocation exclusivement explicite sont préchargées pour l’agent lorsqu’elles sont sélectionnées dans le contexte. Les fichiers personnels, les choix de compétences, les exclusions et les modifications de l’aperçu sont conservés.

Les instructions du projet, notamment celles ciblées par `applyTo` et les fichiers `AGENTS.md`, sont découvertes par Copilot. Le panneau **Compétences et instructions chargées** montre les chargements confirmés et les instructions effectivement consultées : provenance, chemin, heure et contenu transmis, conservés dans chaque tentative. Une compétence disponible ou une instruction détectée n’est jamais comptée comme chargée sans preuve.

Les validations humaines, les restrictions en lecture seule et les permissions restent en place. Les autorisations intégrées aux skills et les hooks de fichiers ne sont pas activés. Les discussions libres et les anciennes sessions gardent leur périmètre.

Le démarrage est compatible avec la suppression de `--no-remote` dans Copilot CLI 1.0.103 ; les sessions restent configurées en local.
