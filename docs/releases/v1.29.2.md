# Feature Studio 1.29.2 — Compétences natives préchargées

Corrige le refus « Le runtime ne propose pas le chargement natif des compétences sélectionnées » lorsque toutes les compétences sélectionnées interdisent l’invocation automatique (`disable-model-invocation: true`).

Ces compétences continuent d’être préchargées par le runtime pour l’agent sélectionné. L’outil `skill` n’est désormais requis que lorsqu’au moins une compétence du contexte est invocable à la demande. Les sélections mixtes gardent les deux modes. Les permissions, les exclusions de contexte et les preuves de chargement restent en place.

Le contrôle reste bloquant pour une véritable absence d’outil de chargement à la demande, avec le nom des compétences concernées et le catalogue reçu. Les fichiers personnels et les versions du SDK/CLI ne sont pas modifiés.

Installe `feature-studio-1.29.2.vsix`, recharge VS Code et relance la même étape.
