# Feature Studio 1.40.0

Ton atelier peut être révisé par une IA externe, puis mis à jour avec une comparaison et un retour arrière. Tu peux également supprimer les kits et agents devenus inutiles sans casser une session en cours.

- **Atelier → Kits → Réviser tout l’atelier** exporte un ZIP contenant les agents, skills, équipes et ressources en fichiers lisibles, un inventaire et les consignes de révision. Les versions fournies, personnelles et propres au projet sont conservées séparément. Les connexions locales restent sur la machine.
- **Comparer un atelier révisé** présente le contenu actuel et proposé, les ajouts, modifications, suppressions explicites et conflits. Les modifications locales intervenues depuis l’export sont protégées. L’application vérifie les références et les parcours avant d’écrire.
- **Historique et restauration** permet de retrouver l’état précédant un import, même après redémarrage. Une modification ultérieure d’un fichier bloque son remplacement. Export, comparaison, application et restauration ne consomment aucun appel Copilot.
- **Supprimer** est disponible dans les bibliothèques Agents et Kits. La confirmation indique les agents, équipes dépendantes et skills retirés, ainsi que les éléments partagés conservés. Les profils fournis supprimés restent retirés après redémarrage ; les fichiers éditables concernés sont effacés.
- **Sessions protégées** : la suppression est bloquée si un agent concerné est utilisé dans une session non terminée d’un projet enregistré, y compris une session archivée, un sous-plan ou une composition en attente. La vérification est répétée avant application ; les historiques des sessions terminées restent consultables.

La réimportation de révision nécessite le projet et le compte ayant produit l’export. Les kits `.fskit.json` restent le format de transfert entre machines. Une révision structurellement valide n’est pas une preuve d’amélioration du comportement : le compte rendu externe peut proposer les missions à comparer.

Le [guide de révision et de restauration](../REVISION-ATELIER.md) et le [guide des kits](../KITS.md) détaillent les formats et les contrôles.
