# Feature Studio 1.11.0 — Zoom, détection Copilot et crédits

Cette version réunit les améliorations du cockpit et les branches intégrées dans `main` le 17 octobre 2026.

- **Zoom global** : mode Auto ou pourcentage fixe de 80 à 200 %, depuis l'en-tête ou les réglages d'apparence. La préférence est personnelle et conservée entre projets ; les menus, dialogues et détails des crédits s'adaptent à l'espace disponible après zoom.
- **Copilot détecté automatiquement** : recherche dans le PATH de VS Code et les installations utilisateur, en ignorant les lanceurs intermédiaires de VS Code. Le diagnostic affiche le chemin utilisé et sa provenance. Le bouton **Détection automatique** remplace un chemin périmé ; un chemin personnalisé reste prioritaire.
- **Ouverture directe** : l'icône et les commandes ordinaires ouvrent le cockpit dans la fenêtre VS Code courante. La commande de fenêtre dédiée et le raccourci Windows restent disponibles.
- **Crédits du compte dans l'en-tête** : consultation des montants, du renouvellement et des détails disponibles. L'actualisation suit la visibilité du cockpit ; une information indisponible reste signalée comme telle.

La connexion au démarrage, les améliorations ergonomiques, les quêtes et les discussions liées aux comptes rendus sont conservées.

Télécharge [feature-studio-1.11.0.vsix](https://github.com/MattDevBzh/KerAI/releases/download/v1.11.0/feature-studio-1.11.0.vsix), installe-le avec **Extensions : Installer à partir du VSIX**, puis recharge la fenêtre. La fiche Feature Studio doit afficher **1.11.0**. Compare l'empreinte du fichier téléchargé avec sa ligne dans le [SHA256SUMS de cette release](https://github.com/MattDevBzh/KerAI/releases/download/v1.11.0/SHA256SUMS).

Les résultats de validation et leurs limites sont consignés dans [VALIDATION.md](https://github.com/MattDevBzh/KerAI/blob/v1.11.0/docs/VALIDATION.md). Les tests utilisent des profils isolés et n'envoient aucun prompt Copilot payant.
