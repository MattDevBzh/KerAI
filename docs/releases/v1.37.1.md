# Feature Studio 1.37.1 — navigation fiabilisée après vérification globale

Cette version corrige des cas limites de navigation identifiés après la livraison 1.37.0.

- **Bonne donnée métier** : le mode « atteindre » ne saute plus la sélection du garage ou de la voiture lorsque l’écran d’arrivée est déjà visible. L’identité demandée est vérifiée.
- **Paramètres cohérents** : les valeurs par défaut sont visibles et conservées dans le contexte des agents. Un paramètre obligatoire vide, même composé d’espaces, bloque le rejeu avant toute interaction.
- **Révision choisie** : créer une correction ne bascule plus silencieusement vers une révision publiée entre-temps. Il faut actualiser la sélection pour utiliser cette nouvelle révision.
- **Captures comparables** : une capture reçoit une clé de comparaison seulement après un rejeu réussi correspondant aux paramètres sélectionnés. La page fait partie de cette clé. Une action libre, un enregistrement ou un rejeu rejeté invalide l’association précédente.
- **Accès sélectionné** : préparer le navigateur conserve l’accès affiché, même après un ancien import ou enregistrement.

Les tests de régression couvrent les défauts reproduits. La publication passe par les suites automatiques Linux et Windows, les tests d’interface et le chargement du VSIX dans VS Code avec navigation. Les essais utilisent des applications synthétiques et n’envoient aucun prompt Copilot payant ; la connexion et les données de votre application réelle restent à vérifier sur votre poste.

Installez le VSIX joint avec **Extensions → Installer à partir du VSIX**, rechargez VS Code puis vérifiez **1.37.1**. Le fichier `SHA256SUMS` joint permet de contrôler le téléchargement.
