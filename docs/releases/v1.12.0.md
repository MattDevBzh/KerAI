# Feature Studio 1.12.0 — Métro, Tour de contrôle et tickets Azure DevOps

- **Dashboard Métro** : une nouvelle vue de suivi avec une ligne de métro par session, l’agent courant, les étapes validées, les attentes humaines et les erreurs. L’ancienne page d’accueil s’appelle désormais **Sessions**.
- **Tour de contrôle** : le dashboard s’ouvre dans une fenêtre séparée pour un second écran, avec une disposition compacte et un bouton plein écran. Les deux fenêtres partagent les mêmes sessions ; les interventions ramènent à la bonne étape dans le cockpit.
- **Modules personnalisables** : Sessions, À traiter, PR, Tickets, Consommation et Activité récente. Ajout, duplication, déplacement, taille, titre et filtres propres à chaque module sont enregistrés. Les sessions évoluent en direct et Azure se rafraîchit à la fréquence choisie, avec date de mise à jour et erreurs explicites.
- **Tickets Azure DevOps** : recherche sur tous les types du projet, filtres combinables, liste compacte et détail complet à la demande : description, critères d’acceptation, champs personnalisés, commentaires datés et liens.
- **Du ticket au développement** : préparation d’une session avec projet cible, dossier courant ou worktree, référence de départ vérifiée, branche, consignes et commentaires sélectionnés. Le contexte importé reste traçable. La session créée attend ton choix d’équipe et ton lancement explicite ; un nouvel essai retrouve la session existante.
- **Navigation regroupée** : Atelier réunit Parcours, Agents, Skills, Kits et Consommation ; DevOps réunit Azure DevOps, Tickets, PR et Livraison. Les Réglages passent dans l’en-tête, à côté des crédits globaux Copilot.
