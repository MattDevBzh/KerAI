# Feature Studio 1.26.0 — Des sessions plus lisibles

Les sessions donnent un accès direct au travail en cours. Sélectionner une carte amène à son détail ; le raccourci en tête de page permet de retrouver l’étape active sans traverser les réglages.

Les **sous-équipes** affichent leur mission avant le contexte complet, qui reste dépliable. Le bandeau de navigation indique le niveau, l’itération et son état. Les tâches actives, validées, retirées ou à revérifier se distinguent dans l’historique ; une recherche et des filtres apparaissent pour les grandes listes. La progression exclut les résultats qui demandent une nouvelle vérification.

Le bouton d’une carte **Sous-plan** ouvre directement la composition de sa sous-équipe. Les panneaux imbriqués gardent une fermeture accessible et rendent le focus au bon endroit. Les cartes restent distinctes des agents, sans portrait d’orchestrateur, dans les thèmes clairs, sombres et événementiels.

Le **chat** regroupe les outils, réflexions et messages intermédiaires pour mettre les réponses en avant. Les demandes humaines s’ouvrent dans une popin réductible ; le brouillon est partagé avec le chat et attend toujours une validation explicite.

Les **permissions Copilot** peuvent être accordées pour une demande, pour son type pendant la session ou pour les lectures dans le dossier de travail, si le runtime le permet. Les accords ne passent pas d’une session à l’autre et sont effacés lors d’un changement de mode. Les règles imposées par l’organisation et les demandes de contournement restent prioritaires.

Les appels et relances manuels ne sont plus plafonnés par défaut. Les limites déjà choisies restent appliquées et peuvent être ajustées. L’autopilot garde son propre plafond et les validations humaines restent inchangées.

[Guide des sous-plans](../SOUS-PLANS.md) · [Permissions natives](../COPILOT-NATIF.md) · [Validation et limites](../VALIDATION.md).

Les contrôles locaux, l’interface Chromium, le runtime Copilot sans inférence, le chargement du paquet dans VS Code et la CI Linux/Windows sont vérifiés séparément. Les captures utilisent des données de démonstration.
