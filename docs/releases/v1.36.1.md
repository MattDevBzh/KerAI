# Feature Studio 1.36.1 — Outils MCP aux noms longs

Le lancement pouvait échouer avant tout prompt avec « Catalogue d’outils incomplet », notamment pour `repo_pull_request_thread` sur Azure DevOps. Avec l’identifiant de serveur généré, le nom complet atteignait 65 caractères. Copilot CLI le tronquait à 64 caractères, mais Feature Studio filtrait encore sur le nom complet et masquait ainsi cet outil.

La liste autorisée et les contrôles utilisent désormais le nom réellement exposé par Copilot. Le serveur, le nom original de l’outil et les permissions conservent leur identité complète. Les collisions après troncature restent bloquantes. Les configurations et les secrets existants sont conservés, sans migration.

Après installation du VSIX, recharge la fenêtre VS Code puis relance la tentative concernée.

## Vérification

- Régression reproduite puis corrigée sur Copilot CLI 1.0.102 avec le SDK 1.0.20 et un serveur MCP local factice.
- Tests des listes autorisées, de la provenance, des permissions et des collisions de noms ; test du CLI réel inclus dans les validations Linux et Windows.
- Aucun prompt payant ni appel au compte Azure DevOps pendant cette reproduction.
