# Feature Studio 1.9.0 — Une interface à la bonne taille

Les grands écrans disposent d’un affichage plus lisible et de pages plus larges.

- Le bandeau supérieur propose **−**, un choix de taille, et **+**.
- **Auto** adapte l’ensemble de l’interface à l’espace disponible dans la fenêtre.
- Choisis un zoom fixe entre **80 et 200 %** si tu préfères garder la même taille.
- Le choix reste enregistré pour tous tes projets, même après fermeture de VS Code. Il est aussi accessible dans **Réglages → Votre atelier → Taille de l’interface**.
- Les menus, colonnes et fenêtres de dialogue s’adaptent à la place restante après agrandissement.

Le zoom ne lance aucun agent et ne consomme aucun crédit. En cas de refus d’écriture des réglages personnels, le cockpit affiche l’erreur et rétablit le choix enregistré.

Installe le fichier `.vsix`, puis recharge la fenêtre de VS Code. Le mode Auto est actif par défaut.
