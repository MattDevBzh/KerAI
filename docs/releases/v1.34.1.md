# Feature Studio 1.34.1 — Connexion et préparation visibles

Cette correction remplace l’attente opaque « Attends la connexion de la session native » par un suivi du démarrage :

- **Permissions** : le sélecteur attend que la connexion active, ses permissions et son catalogue d’outils soient vérifiés. À la reprise, l’identifiant enregistré d’une ancienne conversation ne la fait plus passer pour une connexion prête.
- **Progression** : la session affiche la préparation, le nombre de fichiers vérifiés pour le point de restauration, puis les étapes de connexion à Copilot.
- **Connexion bloquée** : avant le premier prompt, une attente supérieure à 90 secondes est interrompue avec l’étape concernée et une invitation à lancer le diagnostic Copilot. Un délai global configuré plus court reste prioritaire.
- **Arrêt pendant la préparation** : l’annulation est prise en compte entre les opérations et les fichiers du point de restauration ; aucun prompt n’est envoyé après cet arrêt et aucun point incomplet n’est publié. Les fichiers du projet restent conservés.

Le compteur concerne la préparation du point de restauration ; la vérification du dépôt peut précéder son premier affichage. La durée normale d’une réponse Copilot reste régie par le délai d’exécution configuré.

Installe le VSIX puis recharge la fenêtre VS Code. Vérifie **1.34.1** dans la fiche de l’extension. L’archive et son empreinte SHA-256 sont vérifiées avant publication ; les tests automatiques n’envoient aucun prompt Copilot payant.
