# Feature Studio 1.25.0 — Mes équipes

Le menu **Parcours** devient **Mes équipes**.

Créer ou modifier une équipe utilise maintenant le même compositeur visuel que dans les features : cartes avec avatars, catalogue filtrable d’agents et d’équipes, glisser-déposer et boutons de réorganisation. Une équipe existante peut servir de point de départ, et les sous-plans restent disponibles.

Le nom et la description se règlent dans le compositeur. Les réglages des interventions restent accessibles pour ajuster les agents, modèles, niveaux de réflexion, dépendances et participations. Les paramètres hérités des profils sont conservés. Enregistrer met à jour le modèle d’équipe ; annuler conserve sa version précédente. Les sessions existantes gardent leur propre composition.

Cette version inclut le correctif de compatibilité des outils natifs `grep` / `rg` de la 1.24.1. Aucune migration des données ni mise à jour du SDK ou du CLI n’est nécessaire pour ces changements d’interface.

Installe le VSIX, puis recharge la fenêtre VS Code. Le nouveau menu se trouve dans **Atelier → Mes équipes**.
