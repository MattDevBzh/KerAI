# Feature Studio 1.25.2 — Compatibilité native apply_patch

Corrige le refus de démarrage lorsque Copilot expose `apply_patch` sans `edit` ni `create`. Certains modèles utilisent cet outil de patch pour les deux capacités d’écriture.

Le catalogue complet accepte désormais `apply_patch` **ou** la présence conjointe de `edit` et `create`. La lecture, la recherche, le terminal et les questions humaines restent requis. Les doublons, outils inattendus et outils d’écriture en lecture seule restent refusés ; les permissions sont inchangées.

Les tests incluent le catalogue Windows signalé, les variantes bash/powershell et grep/rg, les catalogues incomplets, la lecture seule et le diagnostic sans prompt.

Versions du manifeste, du lockfile et du VSIX : **1.25.2**. Aucun changement de version du SDK Copilot ou du CLI. Prettier reste non bloquant dans la CI.

Installer `feature-studio-1.25.2.vsix`, recharger VS Code, puis relancer **Vérifier Copilot** et l’agent concerné.
