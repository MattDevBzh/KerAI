# Feature Studio 1.10.0 — Connexion automatique et cockpit plus confortable

Copilot se connecte dès l'ouverture du cockpit dans un espace de travail approuvé. Le compte déjà enregistré sur le poste est réutilisé et les modèles disponibles sont chargés automatiquement. L'interface reste utilisable pendant cette vérification. Si le CLI ou l'authentification manque, le diagnostic explique le problème et le bouton de vérification permet de réessayer après correction. Aucun prompt ni lancement d'agent n'est déclenché au démarrage.

Cette version comprend aussi les **44 corrections de priorité 1 à 5** de l'[audit ergonomique](https://github.com/MattDevBzh/KerAI/blob/v1.10.0/docs/ERGONOMIE.md), parmi 68 évolutions recensées :

- Menu compact avec libellés, recherche des écrans et navigation au clavier ; menu bureau plus lisible.
- Textes, cibles de clic et comptes rendus plus confortables ; actions et contenus longs adaptés aux petites fenêtres.
- Dialogues avec focus et défilement maîtrisés, commandes visibles et fermeture protégée contre les clics à côté.
- Sessions avec compteurs filtrants, tri, dates, progression lisible et réinitialisation des filtres.
- Catalogues d'agents et de skills avec recherche, origine et favoris ; sommaire des réglages et sauvegarde accessible après modification.
- Discussions avec agents disponibles dès l'ouverture, options repliables, historique compact, retour aux derniers messages et aide à l'envoi.

Installez le VSIX joint avec « Extensions : Installer à partir de VSIX », puis rechargez la fenêtre. Vérifiez le téléchargement avec SHA256SUMS. La publication suit les tests Linux et Windows et le chargement du VSIX extrait dans VS Code ; le commit exact est indiqué dans cette release. Les tests utilisent des fixtures et ne valident pas l'authentification de votre compte personnel.
