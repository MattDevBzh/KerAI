# Feature Studio 1.10.0 — Zoom et détection du CLI

Le cockpit s’adapte aux grands écrans avec un zoom automatique ou fixe de 80 à 200 %. Les textes, boutons et avatars changent de taille ensemble. La préférence se conserve entre projets et réouvertures.

Copilot CLI est détecté automatiquement dans le PATH de VS Code, puis dans les installations utilisateur usuelles. Les lanceurs intermédiaires de VS Code sont ignorés : leur présence ne signifie pas qu’un CLI est installé. Le diagnostic affiche le chemin utilisé et sa provenance. Si un ancien `copilot.bat` a disparu, **Réglages → Détection automatique** remplace le chemin périmé par ce mode.

Un chemin personnalisé reste prioritaire. Aucun CLI n’est installé ou mis à jour automatiquement. Le diagnostic n’envoie aucun prompt, et les contrôles de protocole, d’authentification et de confinement des outils restent nécessaires.

Cette version conserve les nouveautés de la v1.9.0 : discussions depuis les comptes rendus et propositions de features ajustables depuis une discussion.

La recette locale et ses limites sont consignées dans [VALIDATION.md](../VALIDATION.md).
