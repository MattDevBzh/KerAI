# Feature Studio 1.14.0 — Les récompenses et l’atelier prennent vie

Cette version réunit les nouveautés visuelles restées dans les sources locales avec les interventions facultatives de la v1.13.

- **Six cadeaux pour tes trophées.** Noob à 5, Architecte du dimanche à 20, feu d’artifice Eiffel à 40, Matrix à 70, Dresseur d’agents à 110 et chaton à 200. Dans **Quêtes**, la prochaine récompense affiche son aperçu, sa jauge et les trophées restants. Les trophées déjà gagnés comptent et ne sont jamais dépensés. Active les cadeaux débloqués depuis **Mes récompenses**.
- **Un QG vivant dans chaque session.** Coche **Afficher le QG vivant**, à côté de **LE PARCOURS**. Les postes suivent les étapes réelles et ouvrent leur détail. Le décor suit ton thème ; le choix est conservé entre projets. La vue classique reste disponible en décochant, avec tes brouillons et ta sélection conservés.
- **Le dojo secret Dragon Ball.** Sur **Dashboard** ou sa Tour de contrôle, clique dans le contenu puis saisis **↑ ↑ ↓ ↓ ← → ← →**. Shenron révèle le thème, ses vingt costumes et son nouveau QG. Le thème reste ensuite disponible dans les réglages. Les champs de saisie et les dialogues ignorent la combinaison.
- **Les étapes facultatives dans le QG.** Le poste signale le choix humain attendu et les étapes passées restent marquées **Passée · non exécutée**. La validation finale et les comptes rendus conservent cette distinction.
- **Des thèmes et réglages cohérents.** Les thèmes explicites gardent leurs couleurs et costumes avec Bearded Milkshake Vanilla Banana. Le choix du thème annonce sa sauvegarde automatique. Les réglages affichent la confiance réelle du projet et permettent d’ouvrir l’écran d’approbation VS Code en conservant le formulaire.
- **Des effets maîtrisés.** Le chaton respecte les animations réduites ; le feu d’artifice suit la validation finale ou la relecture explicite. Rouvrir une session terminée ne rejoue pas la célébration, y compris avec les animations réduites. Les couleurs forcées du système restent prioritaires.

Les contrôles de publication vérifient maintenant les quatre fonctionnalités dans les bundles et comparent tous les visuels du VSIX avec les sources, avant de charger le paquet dans VS Code.

Télécharge [feature-studio-1.14.0.vsix](https://github.com/MattDevBzh/KerAI/releases/download/v1.14.0/feature-studio-1.14.0.vsix), utilise **Extensions : Installer à partir du VSIX**, puis recharge la fenêtre. La fiche Feature Studio doit afficher **1.14.0**. Le [SHA256SUMS](https://github.com/MattDevBzh/KerAI/releases/download/v1.14.0/SHA256SUMS) permet de vérifier le fichier téléchargé.
