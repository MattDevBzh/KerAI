# Feature Studio 1.8.0 — Les quêtes de l’atelier

Apprenez à utiliser le cockpit avec 100 quêtes : 16 séries de cinq paliers et 20 défis uniques. Lancez votre première feature, composez vos équipes, créez des agents, répondez aux questions et faites réussir six agents différents de suite dans une même feature.

Chaque quête rapporte de 1 à 10 trophées. Le total apparaît dans le menu Quêtes, sur bureau comme sur petit écran. Le carnet affiche la progression, les conditions, la collection et les missions accomplies. Une série dévoile automatiquement son prochain palier. Les trophées s’accumulent ; les bonus viendront plus tard.

Les actions réellement enregistrées par l’hôte déclenchent les récompenses, une seule fois. Les échecs, les aperçus et les sauvegardes répétées ne créent pas de fausses réussites. La progression reste enregistrée sur cet ordinateur, commune aux projets, après fermeture du cockpit ou suppression d’une session. Un fichier illisible est conservé et signalé.

Les sept ambiances de la v1.7.0 et les vingt costumes Halloween sont inclus. Les profils, la mémoire et les sessions existantes sont conservés. Les missions donnent des indications et ouvrent l’écran utile ; elles ne lancent pas d’opération à votre place.

Installez le VSIX joint avec « Extensions : Installer à partir de VSIX ». Vérifiez le téléchargement avec SHA256SUMS. La publication suit les tests Linux et Windows et le smoke du paquet extrait dans VS Code ; le commit exact est indiqué dans cette release.
