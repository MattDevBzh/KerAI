# Feature Studio 1.28.0 — Images, documentation et dossier de preuves

## Les nouveautés

- **Captures dans le besoin et le chat** : ajout de fichiers PNG/JPEG/WebP ou collage, aperçu agrandissable, retrait avant envoi et conservation dans la session. Les pixels sont transmis comme pièces jointes au modèle compatible, avec refus explicite si sa capacité visuelle n’est pas disponible.
- **Kit Documentation technique** : quatre rôles complémentaires — recherche dans le code et sur le web, plan du document, rédaction, relecture technique et sources. Chaque étape attend ta validation ; les profils de documentation sont limités à la lecture, avec accès web uniquement pour la recherche et la relecture.
- **Quatre exports** depuis le livrable affiché : Markdown, Word, PowerPoint et HTML autonome. Les exports sont locaux, sans appel de modèle supplémentaire. Les liens directs ou par référence et les notes de sources sont conservés.
- **Dossier de preuves** dans l’onglet Preuves : captures, lectures de code, pages consultées, contexte chargé, résultats de tests, livrables et validations. Les conclusions de l’agent et les appréciations humaines gardent leurs justificatifs et leur historique. Une contradiction actuelle empêche la validation tant qu’elle n’est pas résolue.
- **Revérification explicite** : comparaison des empreintes des fichiers associés aux tests, sans relancer les tests. Une nouvelle version, une écriture observée ou une source absente signale les éléments à revoir.

Le catalogue personnel n’est pas remplacé. Les contrôles du code avant les tests et les permissions Copilot restent en place. Les compétences natives de la v1.27.0 restent disponibles.

## Utilisation et limites

[Images et documentation](../IMAGES-DOCUMENTATION.md) · [Dossier de preuves](../DOSSIER-PREUVES.md) · [Validation détaillée](../VALIDATION.md).

Les captures sont préparées à 2 048 pixels et limitées à quatre par envoi ; une discussion indépendante conserve au plus quatre images au total. Elles restent dans le stockage de la session et sont envoyées au fournisseur du modèle lorsqu’on lance le travail correspondant. Le catalogue du compte doit annoncer un modèle visuel compatible.

Les exports bureautiques utilisent une mise en page sobre, issue du Markdown. Les diagrammes Mermaid, les images externes et le HTML actif ne sont pas rendus comme éléments incorporés. Pour PowerPoint, prévoir des sections synthétiques ; un long texte est paginé et les tableaux sont présentés sous forme de texte. Limites : 2 Mo de texte, 200 diapositives.

La recherche web utilise l’outil natif `web_fetch` et des pages de recherche publiques ; elle dépend des permissions, du réseau et de l’accessibilité des sites. Un lien disponible ne suffit pas à confirmer une affirmation. Le dossier conserve des observations datées ; il ne certifie pas la fraîcheur de tout le dépôt ni celle des pages web.

Les scénarios natifs vérifient le vrai Copilot CLI 1.0.102 et 1.0.103 avec un fournisseur local déterministe, notamment le transfert exact des pixels et les outils réellement exposés. Ils ne constituent pas une évaluation de compréhension d’image ou de rédaction par un modèle réel. La recette avec le compte connecté reste limitée par son catalogue de modèles vide.

## Installation

Télécharger le VSIX et le fichier SHA256SUMS de cette release, vérifier l’empreinte, puis installer le VSIX dans VS Code et recharger la fenêtre. La fiche de l’extension doit afficher **1.28.0**.
