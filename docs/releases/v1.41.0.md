# Feature Studio 1.41.0 — Préparer sa branche avant la session

Les sessions classiques et les sessions issues de tickets proposent désormais le même choix Git : serveur distant, branche de départ et nom de la nouvelle branche. La récupération des références se fait avec `fetch`, sans modifier la branche source par un `pull`.

- Worktree isolé : les modifications locales restent dans le dossier source.
- Dossier courant : choix entre continuer le travail présent et créer une branche ; la création bloque les fichiers modifiés ou nouveaux, les documents non enregistrés dans la fenêtre et les opérations Git en cours.
- Échec réseau : réessai ou acceptation explicite de la dernière version connue ; aucun état périmé présenté comme actualisé.
- Branche existante ou base déplacée : message explicite, saisie conservée et possibilité de revérifier.
- La session est enregistrée après préparation Git et avant tout lancement d’agent. Les choix de serveur et de base sont mémorisés par projet dans la fenêtre.

La préparation des dépendances, des fichiers de configuration et des ports reste hors de cette version. Le chemin multi-projets continue à utiliser les dossiers existants. Les tests Git utilisent des dépôts locaux, y compris un serveur simulé ; ils ne nécessitent aucun prompt payant.
