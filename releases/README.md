# Paquets de Feature Studio

La version actuelle est **1.4.0** : [télécharger le VSIX](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.0/feature-studio-1.4.0.vsix) et son [SHA256SUMS](https://github.com/MattDevBzh/KerAI/releases/download/v1.4.0/SHA256SUMS).

À partir de cette version, les nouveaux paquets sont publiés dans les [releases GitHub](https://github.com/MattDevBzh/KerAI/releases/latest) après validation de la CI. Les VSIX et le fichier `SHA256SUMS` présents dans ce dossier concernent les versions historiques jusqu’à la v1.1.1 et restent conservés.

`npm run package` produit localement `releases/feature-studio-1.4.0.vsix`. Pour installer une version livrée, utilise l’asset `.vsix` de sa release GitHub.
