## Prompt final

Create one production-ready BACKGROUND ART asset for a desktop software team's living headquarters UI. This is an EMPTY ROOM BACKDROP; the actual existing pixel-art avatars and every UI label will be placed on top later. Wide landscape 3:1 composition.
Visual style: elegant crisp handcrafted 2D pixel art, warm cozy professional miniature workshop, forest-green painted walls, honey oak floor, brass lights, tidy books and a few leafy plants. Front-facing ORTHOGRAPHIC stage / dollhouse room with only a very slight downward view onto floor; all workstations will face the viewer. Not isometric, not voxel, not photorealistic, not fuzzy.
Composition is essential for UI use: top 40 percent is dark muted green wall with two warm wall lamps and a narrow decorative shelf close to the top. Bottom 60 percent is an open honey-oak floor / broad stage with softly patterned planks. The entire CENTER 80 percent of the width must remain EMPTY and calm, without any furniture, props or focal objects so frontend character portraits can be arranged in a dynamic row or grid. At the far left edge only, a tall narrow bookcase and a plant. At the far right edge only, a small window with evening greenery and a plant. Decorations low contrast, tiny dust-free warm highlights, strong pixel edges, rich but restrained palette, atmospheric and inviting.
Absolutely NO people, NO characters, NO animals, NO robots, NO desks, NO chairs, NO monitors, NO computers, NO interface, NO text, NO labels, NO logos, NO buttons, NO borders, NO watermarks. Full-bleed background artwork only. The style should feel compatible with chibi pixel-art software developer avatars with large faces and green hoodies, but DO NOT render any avatar.
