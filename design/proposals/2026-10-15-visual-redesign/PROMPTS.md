# Feature Studio — cinq propositions visuelles

Date : 15 octobre 2026.

Génération : outil imagegen intégré, sans CLI. Cinq planches originales, chacune comprenant le mode clair et le mode sombre du même écran.

Statut : propositions soumises au choix de Matt. Aucune direction validée pour la production à ce stade. Le point fonctionnel « Dans les coulisses » est retenu comme direction dans la conversation ; son implémentation ne fait pas partie de ces maquettes.

Les changements de logos ou pictogrammes visibles dans les générations sont exploratoires. Le logo et les avatars approuvés du produit restent la référence tant qu'un autre choix n'est pas explicite. Les exemples de données et statuts sont fictifs.

## 01 — Atelier miniature

[Planche clair / sombre](01-atelier-miniature.png)

Un studio miniature habité : les documents passent de bureau en bureau, avec des coulisses lisibles à côté.

- Clair : Lin, sauge et terre cuite.
- Sombre : Vert forêt, bois sombre et ambre.

### Prompt final

```text
Use case: ui-mockup. Create ONE high-resolution design presentation board for a complete visual redesign of "Feature Studio", a French desktop app to learn agentic software development and work with an agent team. The board contains EXACTLY TWO complete app screen mockups, LARGE and stacked vertically: LIGHT THEME on the TOP HALF, DARK THEME on the BOTTOM HALF. Tall portrait board, approximately 1536x2048 or larger. Each screen is wide desktop aspect ratio. A thin title strip labels the concept; each half clearly labelled "MODE CLAIR" or "MODE SOMBRE". CRITICAL: both screens show THE SAME CONTENT, SAME LAYOUT, SAME AGENTS and SAME SESSION STATE with equally polished typography and equivalent readability. No perspective device mockups, no laptops framing the screen, no browser chrome, no comparison of different functional screens. This is actual UI design, not an advertising poster. Make both screen mockups fill the board with minimal margins.

Functional design brief shared across both modes: visible "Feature Studio" wordmark, compact left navigation "Atelier", "Équipe", "Parcours", "Coulisses", "Journal"; a small team emblem with three geometric robot faces. Current session title "Créer un mini-jeu" with status "Code en cours". Main playful visual shows FOUR distinct agents in a left-to-right work sequence: "Architecte", "Développeur", "Testeur", "Relecteur". Architecte completed with a tick, Développeur actively working, Testeur and Relecteur waiting. Friendly memorable characters with useful state labels, not just a row of generic colored cards. The educational inspector "Dans les coulisses" is prominent on the RIGHT, at least a third of screen content width, with four clearly numbered compact sections:
"1. Reçoit" with two document chips "Plan validé" and "Fichiers utiles".
"2. Utilise" with chips "Lire" and "Modifier".
"3. Produit" with "2 fichiers modifiés" and a button "Voir les changements".
"4. Transmet" with an arrow to "Testeur · après ton accord".
These labels MUST be large and legible. This inspector shows tangible inputs, tools, outputs and handoffs, NOT hidden internal reasoning or vague AI thoughts. Bottom of main area: a compact human checkpoint "À toi de relire" with a primary button "Relire les changements" and secondary control "Pause". Bottom slim progress line "Brief → Plan → Code → Tests → Validation", Code highlighted. Need a credible interface to use for hours: clean controls, restrained ornament, hierarchy, generous spacing, genuine contrast in BOTH modes, no small gray-on-gray labels. Spend image space on visual design and these short useful labels, avoid paragraphs of unreadable microcopy. Do NOT add marketing slogans, XP, scores, currency, fake performance metrics, celebratory effects, release buttons, tool pricing, or random decorative dashboards. Generated concept art only.
Concept title: "01 — ATELIER MINIATURE".
Art direction: a premium cozy miniature creative workshop, wonderfully crafted isometric diorama illustration inside a genuinely usable UI. Warm, friendly, grown-up, tactile. The main workspace is an open cutaway room with four little workstations linked by visible paper-document trays. Distinct charming clay robot coworkers: architect with plans, developer with headphones and a monitor, test robot with a checklist, reviewer with a magnifying glass. Their scale must leave UI labels dominant. Isometric workstations are the main signature; inspector is crisp flat 2D UI with fine soft dividers and small raised chips. Rounded rectangles, soft yet readable sans-serif headings, warm serif accents only in concept title. Light mode: natural linen white, sage green controls, tiny terra-cotta highlights, honey-oak desks, daylight. Dark mode: deep forest-green panels, warm ivory text, dark walnut desks, warm amber task lamps; the same miniature studio now lit in evening, with clear blue developer activity and sage action buttons. Rich art-directed dark theme, not merely inverted colors. No plants covering controls, no huge hero headline, no full-screen illustration swallowing the application. Both modes feel like the same calm, inviting working studio.
```
