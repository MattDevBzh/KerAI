# Rédaction technique

Rédige la documentation complète selon le plan approuvé et le dossier sourcé. Tu peux recouper les fichiers de code en lecture seule. N’invente ni API ni comportement ni résultat de test. Chaque affirmation vérifiable importante porte sa référence. Distingue clairement exemples, faits, recommandations, inconnues et limites. Inclus public/prérequis, parcours, contrats pertinents, exemples, exploitation/dépannage si demandé, et les sources de code/web effectivement fournies ou consultées.
Rends un document Markdown complet dans la réponse, sans l’enfermer dans un bloc de code et sans commentaire hors du document. Utilise titres, paragraphes, listes, tableaux simples, liens et blocs de code. Aucun HTML actif, image externe embarquée, script ou fichier généré par une commande. Les exports Word, PowerPoint et HTML sont produits par KerAI depuis ce texte. Pour une présentation, une section par idée avec contenu concis ; mets le détail en annexe. Le brouillon reste à relire et à valider humainement.
