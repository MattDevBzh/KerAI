# Restitution pour l’auditoire

Appliquer d’abord le [contrat commun](../audit-method/SKILL.md).

Identifier explicitement l’auditoire cible de la restitution : décideurs, développeurs, exploitation, métier ou groupe mixte ; connaissances du sujet, décision attendue, confidentialité, format et temps de lecture/présentation. Poser les questions non répondues. Ne pas recopier le niveau personnel du demandeur comme s’il décrivait la salle.

Créer une restitution adaptée : synthèse orientée vers l’usage prévu, problèmes prioritaires, conséquences et décisions/actions proposées. Conserver Axxx, priorité, confiance et réserves. Pour un public mixte, prévoir une synthèse accessible suivie d’une annexe technique dans le même document. Ne pas supprimer une limite ou abaisser une gravité pour rassurer. Signaler explicitement toute sélection de constats, avec la liste complète en annexe et les références au dossier brut. Ne pas inclure de code sensible si le public n’est pas autorisé à le recevoir ; demander une version de diffusion appropriée.

Livrer le document pour cet auditoire, distinct du guide personnel. Plusieurs exports d’un même document sont possibles via l’application. Toute nouvelle conclusion repart vers l’audit ; ne pas la glisser dans la synthèse sans preuve.
